# Barbería El Filo

## Descripción del proyecto

Barbería El Filo es un sitio web informativo para una barbería. El proyecto presenta información del establecimiento y dispone de páginas de inicio y contacto.

## Cómo ejecutar el proyecto

**Para ejecutarlo localmente:**
1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Abre el archivo `index.html` en un navegador web.

**Para visualizarlo en línea:**

Visita el sitio publicado en GitHub Pages:

https://maikmaa.github.io/bitacora-el-filo-2/

## Estructura del proyecto

- `index.html`: página principal utilizada para publicar el sitio en GitHub Pages.
- `inicio.html`: página de inicio del proyecto.
- `contacto.html`: página de contacto.
- `css/`: carpeta que contiene los archivos de estilos CSS utilizados para el diseño visual del sitio.
- `.gitignore`: archivo que indica qué archivos o carpetas debe ignorar Git.

## Tecnologías utilizadas

- HTML
- CSS
- Git y GitHub
- GitHub Pages
